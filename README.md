# Customizable-Skript-Shop


You will need the skript plugin which can be found at: https://www.spigotmc.org/resources/skript.114544/ if you do not have it already


A fully customizable shop script made entirely in Skript (.sk), made for any minecraft servers using Skript.


Make sure you read the comments that I have left, as they can prove useful if they are needed for new skript users.


If you do decide to use this skript, please refer to the License.
